Changelog Mini Me

# 1.2.2
- Various tweaks to the Mini Me Factory 
- Removed all processing except for crafting recipes
- Search bar is now bigger and covers the top of the menu
- Stock config reworked to a cleaner gui listing all item stacks with values, use scroll wheel to increase / decrease the stock counts
- Shift clicking out a crafting recipe now caps at a stack at a time

# 1.2.1
- Moved config into bbl
- Removed some unused config settings
- Changed some items to instructions to tags
- Fixed crashing with some recipe types 

# 1.2.0
- Now requires BBL Core
- Quarry Mini Me can now actually set the quarry size better inside the mini me
- Quarry Mini Me can now set a specific depth range
- Show Area button now uses BBL Utilities line rendering instead of particles 
- Some tasks now have a Configure button to allow for more customization
- Shift Clicking into and out of the mini me now works correctly 
- Instructions are a new item used to define a mini me job inside the new block called the Mini Me Instruction Block
- Added Instruction slot to the mini me 
- Mini Me now shows the armor slot icons
- Mini Me now have a customization menu to enable / disable name plate, Change name and Change skin
- Added Mini Me Factory, can be used to make Mini Mes craft certain items up to a certain amount
- Added Mini Me Constructor (when NeoSync is installed) right click and provide power to create a Mini Me

# 1.0.1
- Enabled auto mod publishing
